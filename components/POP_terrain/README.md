# POP_terrain

Displaces an input grid POP along its normals by a heightmap, producing scrolling retro terrain geometry. The internal `preview` TOP shows a dark-ground wireframe render of out1.

## Inputs
- **in1 - grid (POP):** the surface to displace (a Grid POP; any POP with positions works, a sphere gives a bumpy ball). Unconnected: a built-in grid is used for the preview.
- **in2 - heightmap (TOP):** used when `Heightsource` = input. If unconnected, the internal noise is used (no warning).
- **in3 - modulation (CHOP, optional):** `band1` scales Height, `band2` scales scroll speed, `beat` adds a height pulse. Other channels are ignored.

## Outputs
- **out1 - terrain (POP):** the displaced points with a height-based `Color` attribute and recomputed normals.

## Parameters
Controls
- `Heightsource` (noise | input): internal scrolling noise or the in2 TOP.
- `Style` (smooth | ridged | terraced): shaping of the heights.
- `Height`: displacement amount in world units.
- `Scale`: noise feature frequency (noise source only).
- `Terraces`: number of steps for the terraced style.
- `Speed`: scroll speed of the heightmap (animation uses absolute time).
- `Seed`: noise seed.

Look
- `Look` (original | mono), `Accent`: colour of the Color attribute (red accent on peaks).

Heightmap UVs are generated by a planar projection of the input's bounding box, so any input shape can be sampled.
