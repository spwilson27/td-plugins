# POP_terrain

Displaces an input grid POP along its normals by a heightmap, producing scrolling retro terrain geometry. The internal `preview` TOP shows a dark-ground wireframe render of out1.

## Inputs
- **in1 - grid (POP):** the surface to displace (a Grid POP; any POP with positions works, a sphere gives a bumpy ball). Unconnected: a built-in grid is used for the preview.
- **in2 - heightmap (TOP):** used when `Heightsource` = input. If unconnected, the internal noise is used (no warning).
- **in3 - modulation (CHOP, optional):** `band1` scales Height, `band2` scales scroll speed, `beat` adds a height pulse. Other channels are ignored.

## Outputs
- **out1 - terrain (POP):** the displaced points with a height-based `Color` attribute and recomputed normals.

## Parameters
Controls
- `Heightsource` (noise | input): internal scrolling noise or the in2 TOP.
- `Style` (smooth | ridged | terraced): shaping of the heights.
- `Height`: displacement amount in world units.
- `Scale`: noise feature frequency (noise source only).
- `Terraces`: number of steps for the terraced style.
- `Speed`: scroll speed of the heightmap (animation uses absolute time).
- `Seed`: noise seed.

Look
- `Look` (original | mono), `Accent`: colour of the Color attribute (red accent on peaks).

Heightmap UVs are generated by a planar projection of the input's bounding box, so any input shape can be sampled.

## Implementation
No GLSL. Height shaping happens on the heightmap image (512 x 512 float TOPs); the points only read it.
* `hmap` (Switch: noise / in2). `in2_luma` (Reorder TOP, luminance) converts a picture; the internal noise is already grey. `noise_contrast` (Level TOP) stretches the noise contrast, as before; in2 maps are left alone.
* **Style** is a Switch TOP over three native chains (only the selected one cooks): *smooth* = unchanged; *ridged* = `(1-|2h-1|)^2` from Math TOPs (2h-1, abs, 1-x, square); *terraced* = `(floor(h*k) + smoothstep(0.35, 0.65, fract(h*k))) / k` from Math (floor), Composite (subtract / multiply / add), Level and Math TOPs.
* **Lookup Texture POP** `read_height` samples `style` at each point's texture coordinate `Tex(0)`, `Tex(1)` into attribute `Hgt`. Scrolling is the Lookup's v index offset (`Speed`, `band2`), mirrored at the edges, so the heightmap images only recook when a parameter changes.
* **Math Combine POP** `displace_and_colour`, one block per step: `Hgt * Height` (band1 / beat swell it), `P = N * displacement + P`, then the colour: clamp, smoothstep, Mix between blue and bone (Look original) or grey ramp (Look mono), red accent `Accent * smoothstep(0.75, 1, t)`, and the `0.35 + 0.9 t` shading. The result is written to `P` and `Color`.
* Differences from the old shader: grey from `in2` uses the Reorder TOP luminance weights (Rec. 709) instead of 0.299/0.587/0.114; heights are sampled from a 512 float image by the Lookup POP (mean difference 0.0006 world units, up to about 0.02 on sharp ridged edges).
* **Bench** (`tools/bench.py --against` the old GLSL tox, GPU ms, old -> new, 1280x720 / 1920x1080; POP components do not depend on resolution): 1.04 -> 1.04 (0 %), 1.04 -> 1.02 (-2 %). A second run of the same harness counting only ops that cooked that frame: 1.03 -> 1.15 (+12 %), 1.07 -> 1.01 (-5 %). (The shipped bench adds up `gpuCookTime` of every op every frame, including ops that did not cook that frame, which over-counts static native nodes; the second figure counts only ops that cooked. The GPU was shared with other jobs, so single runs vary by 10-20 %.)
